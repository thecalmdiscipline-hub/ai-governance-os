## 1. Project overzicht

**Valqeron** is een B2B SaaS-platform dat bedrijven helpt AI-systemen gecontroleerd te deployen, besturen en monitoren via een centrale "control layer" (Valqeron Core). Propositie: *gecontroleerde AI in plaats van gefragmenteerde tools* — governance, audit-logging, risicobeheer en 10 kant-en-klare AI-workflows in één omgeving, gepositioneerd richting EU AI Act / ISO 27001 / ISO 42001-compliance.

- **Doelgroep:** B2B, met name bedrijven vanaf €1M+ jaaromzet die operationele AI-automatisering willen met oversight (zie ICP-tekst in `app/workflows/implementations/sales_lead_qualification.py:37`).
- **Stack:** FastAPI + PostgreSQL (prod) / SQLite (dev/test) + OpenAI (`gpt-4o-mini`). Multi-tenant via `organization_id` op elke tabel (single-tenant-per-organisatie isolatie, geen aparte databases).
- **Frontend (oud, gepensioneerd 2026-09-18):** React 18 via CDN (Babel standalone, geen build tooling), was geserveerd als static files door FastAPI. `app/static/app.jsx` — dit was de marketing/product-SPA op `app.`/`api.`/`compliance.valqeron.com`. De bestanden staan nog in `app/static/` als referentie maar worden nergens meer geserveerd.
- **Frontend (nieuw, klantportaal, live sinds 2026-09-18):** `ai-governance-frontend` — apart Vite + React 19 + TypeScript-project op de Mac (`/Users/dennisschetters/ai-governance-frontend`, **geen git-repository**), gedeployed als static build (`npm run build` → `dist/`) naar `app.valqeron.com` via nginx (los van de FastAPI-backend). Praat cross-origin met de backend via `VITE_API_BASE=https://api.valqeron.com`. Zie sectie 2/4/6 voor de deploy-status.

## 4. Openstaande kritieke acties (prioriteitsvolgorde)

Volgorde is een inschatting op basis van wat er in de code ontbreekt en wat sales/compliance blokkeert. Tijdsinschattingen zijn indicaties, geen harde toezeggingen — pas aan waar je betere info hebt.

0. ~~**KRITIEK — `app.valqeron.com` toont een lege/kapotte pagina aan elke bezoeker**~~ — **opgelost en visueel geverifieerd op 2026-09-17 (tweede, aanvullende fix nodig gebleken)**
   Was: `nginx/sites/app.valqeron.com.conf` had een Content-Security-Policy-header (`script-src 'self'`) die de CDN-scripts blokkeerde waar `app/static/index.html` van afhangt (React, ReactDOM en Babel-standalone via unpkg.com, plus Google Fonts). Eerste fix gecommit als `31ecf6b`, gedeployed via `scripts/deploy.sh` + handmatige nginx-config-kopie (dat script synct `nginx/sites/*.conf` niet naar `/etc/nginx/sites-available/`) + `nginx -t && systemctl reload nginx`. Die eerste keer is alleen via `curl`/headers geverifieerd, niet visueel — en dat bleek onvoldoende: de pagina bleef leeg. Root cause #2 (gevonden bij een echte visuele/browserconsole-check): Babel-standalone transpileert `app.jsx` in de browser en voert het resultaat uit via een geïnjecteerde **inline** `<script>`-tag — een aparte CSP-categorie dan de externe `unpkg.com`-scripts die de eerste fix al toestond. Tweede fix (`'unsafe-inline'` toegevoegd aan `script-src`) gecommit als `0306361` ("Fix second CSP violation on app.valqeron.com: allow inline script for Babel-standalone"), gepusht, en op dezelfde manier gedeployed (deploy.sh + handmatige nginx-config-kopie + reload). **Dit keer wél visueel geverifieerd**, met een headless Chrome (via Playwright, `channel: 'chrome'`, systeem-Chrome op de Mac) tegen de live `https://app.valqeron.com`: `#root` bevat 18.036 tekens gerenderde HTML, de zichtbare bodytekst bevat de daadwerkelijke marketing-copy/navigatie, geen enkele CSP-gerelateerde consolemelding, geen `pageerror`'s. Eén ongerelateerde, pre-existing 404 in de console bleek een ontbrekende `/favicon.ico` (bevestigd met `curl`) — cosmetisch, geen CSP-issue, buiten scope van deze fix. `compliance.`/`api.valqeron.com` blijven ongewijzigd bereikbaar (regressiecheck, 200 OK). Les voor volgende keer: bij een CSP/rendering-fix altijd een echte browsercheck doen, niet alleen `curl`/headers — die tonen alleen of de server de juiste header stuurt, niet of de pagina daadwerkelijk rendert.

   Dit punt is op basis van een gecachte browsercheck geopend en met een verse, cache-geforceerde check weer gesloten: `valqeron.com`/`www.valqeron.com` draaien inderdaad op een andere host (217.160.0.147) dan de droplet, maar tonen daar wél de actuele, correcte content en pricing. 2. ~~**AVG-anonimiseringslaag (Presidio of vergelijkbaar)**~~ — **volledig live in productie, incl. telefoonnummerfix (2026-09-18)**
   Was: niet gestart — niets in de codebase.
   Nu: Microsoft Presidio (self-hosted) + spaCy NL/EN-modellen, gebouwd als `app/core/pii_anonymizer.py` en verplicht bekabeld vóór de OpenAI-call in alle 10 workflow-implementaties.
